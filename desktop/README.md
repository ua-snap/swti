# macOS desktop app

The Statewide Temperature Index can be built as a stand-alone macOS app. It
bundles Python, the Dash app and its data into a single `.app`; users need
nothing else installed. The app still needs an internet connection to fetch
current station data from the ACIS API.

## How it works

`swti_desktop.py` starts the existing Dash/Flask app on a private
`127.0.0.1` port (chosen at random) in a background thread, and shows it in a
native window using [pywebview](https://pywebview.flowrl.com/) (the system
WebKit, like Safari). [PyInstaller](https://pyinstaller.org/) freezes it into
an app bundle.

Differences from the hosted site, all switched on by `SWTI_DESKTOP=1` (set by
the launcher):

* No web analytics script.
* The generated CSV is written to `~/Library/Caches/edu.alaska.uaf.accap.swti/downloads`
  (the app bundle may be read-only). "Download data" and the chart's camera
  button open a Save dialog.
* Links to other sites open in the default browser.
* The packaged app ignores `FLASK_DEBUG` and always uses live data.
* Logs go to `~/Library/Logs/Alaska Statewide Temperature Index/swti.log`.

## Building

Requires macOS and Python 3.13 (e.g. `brew install python@3.13`).

```
desktop/build_macos.sh
```

This creates `.venv-desktop/`, installs `desktop/requirements.txt`, and writes:

* `dist/Alaska Statewide Temperature Index.app`
* `dist/Alaska Statewide Temperature Index.dmg` (drag-to-Applications installer)

The app is built for the architecture of the Python used: arm64 on Apple
silicon, x86_64 on Intel. Build on each architecture you need to support.

To run the desktop shell without packaging (uses your environment, so
`FLASK_DEBUG=True` still selects the local test data):

```
.venv-desktop/bin/python desktop/swti_desktop.py
```

The icon (`swti.icns`) is generated by `desktop/make_icon.py`.

## Distributing

The build is ad-hoc signed, which is enough to run it on the machine that
built it. On other Macs, Gatekeeper will block an unsigned download; users can
right-click the app and choose **Open** (or allow it in System Settings →
Privacy & Security).

To distribute without that warning, sign it with an Apple Developer ID and
notarize it:

```
codesign --deep --force --options runtime --timestamp \
    --sign "Developer ID Application: <Team Name> (<TEAM_ID>)" \
    "dist/Alaska Statewide Temperature Index.app"
xcrun notarytool submit "dist/Alaska Statewide Temperature Index.dmg" \
    --keychain-profile <profile> --wait
xcrun stapler staple "dist/Alaska Statewide Temperature Index.dmg"
```

(Re-create the `.dmg` after signing the `.app`, then notarize the `.dmg`.)
